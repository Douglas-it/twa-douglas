# Tecnologias Web Avançadas — ISLA Gaia (2026/27)

Este repositório contém os trabalhos práticos desenvolvidos na unidade curricular de **Tecnologias Web Avançadas** do 3º ano da Licenciatura em Engenharia Informática.

## 📁 Estrutura do Repositório

* **`twa-ficha01/`**: Exercícios iniciais sobre o ambiente Node.js, configuração de Módulos ES (ESM) nativos, manipulação de strings (gerador de *slugs*) e consumo de APIs públicas através de `fetch` assíncrono com escrita de dados em ficheiro local (`repo.json`).
* **`twa-vite/`**: Aplicação frontend construída sobre um projeto base gerado com a ferramenta Vite (template Vanilla JavaScript). Inclui a implementação de lógica reativa para um contador decrescente com atualização dinâmica do título do separador do browser (`document.title`).

## 🛠️ Tecnologias e Ferramentas Utilizadas

* **Node.js** (v22.x LTS)
* **npm** (v10.x)
* **Vite** (Build tool para Vanilla JS)
* **Git & GitHub** (Controlo de versões)
