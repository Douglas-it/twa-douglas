# twa-douglas

## Uso de IA Generativa
De acordo com as normas da unidade curricular, declara-se que foi utilizada inteligência artificial generativa (como ferramenta de apoio pedagógico e tutoria) durante a realização destas fichas. 
* **Finalidade:** Esclarecimento de dúvidas sobre a sintaxe do JavaScript moderno, explicação de métodos funcionais (map, filter, reduce, toSorted) e apoio na estruturação lógica dos módulos (`catalog.js`, `app.js` e `check.js`).
* **Autoria:** Todo o código implementado foi compreendido, validado e testado manualmente no ambiente de desenvolvimento local.
